# 🗺️ Strategic Objectives

**Path:** `/strategic-objectives/`
**Status:** 🗂 Scaffolded
**Stack:** HTML · React · Google Sheets

---

## Overview

Roles, responsibilities, and OKR tracking tool for Mid TN VBC leadership and directors. Replaces fragmented spreadsheets and verbal role definitions with a single source of truth for staff accountability.

---

## Planned Features

### Roles & Responsibilities
- Staff directory with role definitions
- Responsibility matrix (who owns what)
- Department breakdown
- Reporting structure / org chart

### Task Board
- Club-wide task assignments (from `Club_Task_Assignment_List.xlsx`)
- Status: Todo / In Progress / Done / Blocked
- Assignee, due date, priority
- Filter by department or person

### OKR Tracking
- Seasonal objectives (club-wide and per department)
- Key results with % progress
- Check-in cadence (weekly/monthly)
- Director review dashboard

### Accountability Dashboard
- Open tasks by person
- Overdue items flagged
- Completion rate by department
- Season-over-season comparison

---

## Data Sources

- `Club_Task_Assignment_List.xlsx` — existing task data
- `Coaches_List_Pay_20252026__Coach_PAY__JanuraryJune.csv` — staff reference
