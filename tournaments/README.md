# 🏆 Tournaments Module

**Path:** `/tournaments/`
**Status:** 🗂 Scaffolded
**Stack:** HTML · React · Google Sheets

---

## Overview

Manages both hosted tournament events and team travel logistics for Mid TN VBC.

---

## Planned Features

### Hosted Events
- Event creation and setup
- Court assignments and scheduling
- Volunteer / DIBS shift integration
- Live results entry
- Pool play and bracket management
- Check-in system

### Travel Management
- Team registration portal (external tournaments)
- Results tracking by team
- Travel message board (per trip)
- Hotel block management
  - Room assignments
  - Rooming list generator
  - Check-in/check-out coordination
- Rideshare coordinator
  - Driver sign-up
  - Passenger matching
  - Route grouping by address

### Results Tracking
- Win/loss/set record per team
- Season standings
- Tournament placement history
- Export for USAV reporting
